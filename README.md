# Свадебный сайт-приглашение Артёма и Екатерины

Одностраничный landing: расписание, маршрут прогулки, кофейни и адреса.

**Сайт:** https://romalx.github.io/A-E-wedding/

## Локальный запуск

```bash
npm install
npm run dev
```

## Как поменять тексты

Все тексты, адреса и ссылки — в `src/data/config.ts`.

## Деплой

Push в `main` → GitHub Actions собирает сайт и публикует на Pages.

В репозитории: **Settings → Pages → Source → GitHub Actions**.

## Стек

Vue 3 + Vite + TypeScript + Tailwind CSS 4
